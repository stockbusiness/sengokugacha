### 5.3 報酬の上限値 — 決定済み（2026-08-22）

| 項目 | 値 |
|---|---|
| 1回あたり最大 | 3,000 OVE |
| 1ユーザーあたり累計最大 | 3,000 OVE |
| 同一ミッションの付与 | 1回まで |
| 累計の管理単位 | `rule_code` 単位、`external_user_id` 単位 |
| OVE残高の有効期限 | 無期限 |

3,000 OVE は「1回で付与できる最大値」であり通常額ではありません。ミッション構成確定後、通常付与額はこれより低い値へ設定します。

**fail-closed の方針**：`reward_rules` 未登録 / 上限未設定 / 上限超過 は**すべて付与拒否**。自動再送時も累計上限を再確認し、同じ `idempotency_key` では二重付与しません。一括遡及付与は行いません。

**Wallet 側への相談事項**：`reward_rules` が有効期限日数を必須としている場合、任意の期限は設定せず「無期限」を表現できる方法をご教示いただく（返信案に記載済み）。
