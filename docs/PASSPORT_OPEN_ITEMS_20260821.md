### C6. cron の1本だけ実行記録がありません

**背景**

`CRON_SECRET` の設定により cron は動き出しましたが、**3本のうち `cron_integration_outbox_drain` だけ実行記録が確認できていません**。

| cron | 間隔 | 実行記録 |
|---|---|---|
| `cron_notification_outbox_drain` | 10分 | ✅ あり |
| `cron_reconciliation` | 30分 | ✅ あり |
| **`cron_integration_outbox_drain`** | 10分 | ❌ **未確認** |

`integration_outbox_events` は現在空のはずで、処理対象ゼロで即座に成功するのが期待動作です。**それが落ちているなら、実データが入る前に直しておくべき不具合**です。PR-P1c の Outbox はこの仕組みの上に乗るため、先に確認しておきたい項目です。

**確認していただきたいこと**

まず記録の有無を再確認してください。

```sql
select action, details, created_at
from admin_audit_logs
where action like 'cron\_%'
order by created_at desc
limit 20;
```
