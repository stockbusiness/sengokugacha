## Supabase側で確認する方法(参考、`stockbusiness`向け手順)

1. Supabase Dashboard → 対象プロジェクト → 左メニュー「Database」→「Backups」を開く
2. 「Scheduled backups」欄に直近のバックアップ一覧が表示される(Freeプランの場合は日次バックアップが自動で有効、保持期間はプランに依存)
3. PITR(秒単位の任意時点への復元)はProプラン以上でのみ利用可能。有効化されている場合は同画面に「Point in Time Recovery」セクションが表示される
4. 実際に復元を試す場合は、必ず**別プロジェクトへの復元(Restore to a new project)**を選び、本番相当の既存ステージングプロジェクトを上書きしないこと
