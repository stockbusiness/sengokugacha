**確認済みの安全な復元手段**: Backups画面に「Restore to new project」(BETA)タブがあり、既存のステージングプロジェクトを上書きせず、**別の新規プロジェクトへ復元**する機能が用意されている。実際に復元を試す場合は必ずこちらを使うこと(既存プロジェクトへの直接「Restore」は不可逆的にステージングDBを上書きするため、テスト目的では使わない)。

**リスクとして残る点**: PITRが無効なため、復元できるのは直近の日次バックアップ時点(最大で約24時間分のデータロスの可能性)までであり、秒単位の任意時点への復元はできない。Stripe実接続後に本番相当データが投入される段階までに、PITR有効化(月額$100〜$400、保持期間7/14/28日で選択)の要否を`stockbusiness`に再度判断していただくことを推奨する。

## Supabase側で確認する方法(参考、`stockbusiness`向け手順)

1. Supabase Dashboard → 対象プロジェクト → 左メニュー「Database」→「Backups」を開く
2. 「Scheduled backups」欄に直近のバックアップ一覧が表示される(Freeプランの場合は日次バックアップが自動で有効、保持期間はプランに依存)
3. PITR(秒単位の任意時点への復元)はProプラン以上でのみ利用可能。有効化されている場合は同画面に「Point in Time Recovery」セクションが表示される
4. 実際に復元を試す場合は、必ず**別プロジェクトへの復元(Restore to a new project)**を選び、本番相当の既存ステージングプロジェクトを上書きしないこと
