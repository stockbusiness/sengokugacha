## 3. 【要判断】付与ルールの登録内容が、こちらの意図と食い違います

Wallet の提案は次のとおりです。

| 項目 | Wallet 提案 |
|---|---|
| `reward_amount` | **3,000**（1回あたりの付与額） |
| `per_user_limit` | **1**（1ユーザーにつき通算1回） |
| `per_event_limit` | 1（同一ミッションにつき1回） |

**これは「1回3,000 OVE を1回だけ渡す」設定です。** こちらの決定は次でした。

> 1回あたり最大 3,000 OVE / 1ユーザーあたり**累計**最大 3,000 OVE / 同一ミッション1回
> **3,000 OVE は「1回で付与できる最大値」であり通常額ではない。「はじまりの旅」の総額が 3,000 OVE で、これを複数のミッションに分けて段階付与する。**

つまり**「総額3,000を分割して複数回」**が意図で、**「3,000を1回」ではありません**。

Wallet 側もこの可能性に気づいており、§4 で「ミッションが複数ありそれぞれで付与される設計でしたら、`per_user_limit` はミッション数に合わせるか、外していただく必要があります」と確認をくださっています。

## 5. 【ご照会】付与ルールの登録内容について

**恐れ入りますが、ご提示の内容はこちらの意図と少し異なっております。** 先に前提をお伝えしたうえで、3点ご照会させてください。

### 5-1. 3,000 OVE は「総額」であり、1回あたりの額ではありません

「はじまりの旅」は、**総額 3,000 OVE を複数のミッションに分けて段階的に付与する**設計です。

こちらからお伝えした「1回あたり最大 3,000 OVE」は、**上限値としての 3,000**という意味でした。1回で 3,000 を渡す想定ではなく、通常の1回あたりの付与額はこれより低い値になります。**説明が足りず失礼しました。**

ご提示の `reward_amount: 3,000` / `per_user_limit: 1` は「3,000 を1回だけ」という設定になるかと存じます。**ご指摘のとおり、ミッションごとに付与される設計です。**

### 5-2. ミッション構成が未確定のため、いまは数値を確定できません

何段階に分けるか、各回いくらかが社内で確定しておりません。

**上限は誤付与を止める最後の砦ですので、構成が固まらないうちに暫定値を入れることは避けたい**と考えております。後から変更する際、すでに付与済みの利用者の扱いが問題になるためです。

つきましては、**ルールの本登録はミッション構成の確定後**とさせていただき、**検証環境では仮のルールで疎通確認だけ先に進める**形をご提案いたします。ご都合はいかがでしょうか。

### 5-3. ご照会3点

構成を決めるにあたり、仕様を確認させてください。

**(1) `reward_amount` と、リクエストでお送りする `amount` の関係**

`reward_amount` はルール側で**額を固定する**ものでしょうか。それとも**上限**として働き、実際の額はリクエストの `amount` で決まるのでしょうか。

前者の場合、ミッションごとに異なる額を付与するには**ミッション数だけルールを分ける**必要があるかと存じますが、その理解で正しいでしょうか。

**(2) `event_id` の送り方**

`per_event_limit` は同一ミッション（`event_id`）につき1回、とのことでした。

**現在こちらがお送りしている項目に `event_id` が含まれておりません**（`idempotency_key` / `external_user_id` / `amount` / `transaction_type` / `rule_code` / `service_code`）。フィールド名と、必須かどうかをご教示いただけますでしょうか。必要であればこちらで実装します。

**(3) 累計「金額」の上限を設定する方法**

`per_user_limit` は**回数**の上限と理解しております。こちらが守りたいのは「**1ユーザーあたり累計 3,000 OVE を超えない**」という**金額**の上限です。

各回が同額であれば `reward_amount × per_user_limit` で表現できますが、**ミッションごとに額が異なる場合、回数制限だけでは累計額を抑えられません**。金額での累計上限を設定できる項目はございますでしょうか。

無い場合は、こちらで各回の額を揃える（均等割にする）ことで対応する想定です。

### 5-4. 月間・全体の発行量上限について

ご提案いただいた任意設定ですが、**「はじまりの旅」の対象は現時点で当方の登録利用者19名**であり、総額も 3,000 OVE × 人数に収まります。**当面は設定不要**と考えておりますが、貴社の運用上あったほうがよろしければご相談させてください。
